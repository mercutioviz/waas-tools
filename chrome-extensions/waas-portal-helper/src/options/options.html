Account banner

Rules decide which tenant you're looking at and how loudly to say so. The first matching rule wins, so put the most specific ones first.

How to write a rule

URL match — a regular expression tested against the full page URL. Good when an account ID appears in the address, e.g. /accounts/12345\b.

Element text — a CSS selector whose text names the account. Press Alt+Shift+I on the portal to turn on the inspector, click the element showing the account name, and paste the copied selector here. Leave the label blank to use that text verbatim, or add an optional regex to extract part of it.

Label backreferences — $0 is the whole match (or the element's text), $1–$9 are capture groups. Example: label $0 — PRODUCTION.

Dismiss dialogs

Dialogs listed here are closed as soon as they appear, before they can paint. One CSS selector per line, each matching a dialog's outermost element.

How this works

The extension clicks the dialog's own close button rather than deleting it, so the portal still releases the page scroll lock it applies while a dialog is open.

To add one, press Alt+Shift+I on the portal, click the dialog's outer edge to copy its selector, and paste it here. Prefer a data-testid if the element has one — the portal's other class names are build hashes that change on every release.

The default entry is the Fair Usage Policy popup that appears on each fresh load of the applications page. Note that it reports a real account condition — suppressing it means you won't be told when that condition changes.

API capture

Turn this on from the toolbar popup when you need to know what one of the portal's own API calls returns — the groundwork for any feature that shows portal data this extension can't otherwise see.

How to run a capture

Turn API capture on in the popup, then reload the portal page — the tap only injects on navigation. Open DevTools and each API call appears in the console, or use Copy capture in the popup to get the whole log at once.

Values are redacted. Key names are kept, strings are reduced to a kind and a length (string:hostname(21)), and numbers appear only where the key names a count or a limit (maxHostnames: 30). So a capture tells you an endpoint returns seven hostnames without telling anyone which seven.

Prefer the popup's copy button over the console. The console also holds the portal's own logging, which is not redacted — and the redaction is a safety net, not a guarantee. Read a capture before pasting it into a ticket, a chat, or this repository.

Behavior

Privacy

This extension makes no network requests and sends nothing anywhere. Rules are stored in Chrome's synced extension storage, which means they travel with your Chrome profile — avoid putting customer names in a label if that matters to you.

API capture observes calls the portal was making anyway. The responses it holds stay in that tab's memory, are capped in size, are never written to disk, and go no further than the console and the popup's copy button.
